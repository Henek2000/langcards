# Flashcards: French & Russian (PWA)

This is an installable, offline-first flashcard app for learning French and Russian A1 vocabulary, with Spanish and English translations. It consists of static files only, so it can be hosted on GitHub Pages under any subpath (all paths are relative).

## Use
- **Menu → Flashcards → language → level → stack (Nouns / Verbs).**
- **Flip a card:** tap it, or press Space.
- **Answer:** swipe right if you knew it, left if you didn't. The arrow keys and the ✗ / ✓ buttons do the same.
- **Card order:** a weighted shuffle. Unseen cards and cards you missed last time come first.
- **Stats:** stored on the device in IndexedDB. Every review is saved as an event, and each word keeps running totals. Stats & settings can export them as JSON, events CSV or words CSV.

## Data
`data/*.json` is generated by `tools/build_packs.py` from `langdb.sqlite`. Every word, gloss, translation and example comes from Wiktionary and the CEFR lists (FLELex, SMARTool, KELLY). The script only selects and formats them. Credits are in `data/credits.json` and on the About screen. `tools/pack_report.json` lists pack sizes and dropped items.

## Release / update flow
1. Change the code or regenerate the packs: `python3 tools/build_packs.py /path/to/langdb.sqlite`.
2. Optionally bump `VERSION`.
3. Run `python3 tools/stamp.py`. It writes `js/version.js` and `sw.js`, with a version + content-hash cache name and the precache list.
4. Commit and push. Installed apps check for a new service worker on launch, every 30 minutes and whenever the app comes back to the foreground. The new version activates right away. On menu screens the app reloads and shows an "Updated to vX" toast; in the middle of a session it offers a Reload button instead.
